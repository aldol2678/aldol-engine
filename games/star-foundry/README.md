# 별 공방 (Star Foundry) — M6 후보 · 물류·생산 자동화

ENGINE-NEXT-01 차세대 공통 코어(`src/core/next/`) 위의 세 번째 신규 장르 실증. 개발 후보이며 공식 채택본이 아니다.

## 규칙
- 원천(별광석 광산, 수정 샘)이 일정 틱마다 아이템을 하나씩 내보낸다. 출구 칸에 벨트가 있고 비어 있어야 나온다.
- 벨트는 12틱마다 한 칸씩 아이템을 옮긴다. 다음 칸이 차 있으면 멈춘다(역압). 아이템은 사라지거나 복제되지 않는다.
- 제련소: 별광석 2 → 별쇠 1 (60틱). 조립기: 별쇠 1 + 수정 1 → 별등 1 (60틱). 기계는 출구 방향 칸으로 결과물을 내보낸다.
- 창고에 별쇠·별등이 들어가면 코인을 받는다. 건물은 코인으로 짓고, 철거하면 50%를 돌려받는다. 코인은 플레이어와 은행 사이에서만 움직인다(총량 보존).
- 주문: 별쇠 3개 납품 → 별등 5개 납품. 모두 채우면 완료, 납기(240초)를 넘기면 실패. 새 게임으로 다시 시작한다.
- 모든 수치(격자, 비용, 레시피, 벨트 속도, 주문, 납기)는 `world.json`의 `game.foundry` 규칙에 있다.

## 조작
- PC: `1` 벨트 · `2` 제련소 · `3` 조립기 · `4` 철거 · `R` 방향 회전 · 방향키로 커서 이동 후 `Enter`/`Space` 설치 · 마우스 클릭으로 칸에 설치/철거 · `F` 배속(x1/x4) · `N` 새 게임 · `M` 음소거
- 모바일: 왼쪽 아래 도구 버튼 4개, 오른쪽 아래 방향·배속·새 게임·음소거 버튼, 칸을 탭해 설치/철거

## 저장
- 키: `aldol-engine.star-foundry-m6.save.v1` (버전형 봉투 `aldol-next-save/1`, 체크섬 포함)
- 설치·철거·납품·주문 완료 때와 300틱마다 자동 저장. 손상되었거나 버전이 다른 저장은 거부하고 새로 시작한다.

## 재사용한 공통 모듈
`ecs`(건물·아이템 엔티티, 이벤트), `spatial`(격자·방향), `inventory`(기계 버퍼 craft, 코인 transfer), `quest`(주문·1회 보상), `runtime`(고정 스텝·시드 RNG·리플레이), `save`, `manifest` + 렌더 `hud.js`(lake 테마), `next/board.js`, `next/shell.js`, `audio.js`.

## 에셋
Three.js 기본 도형만 사용한다(GLB·이미지·외부 에셋 없음). 소리는 기존 WebAudio 합성 음성을 재사용한다. 코드 MIT.
