# 룬 금고 (Rune Vault) — M4 후보 · 탑다운 퍼즐 탐험

ENGINE-NEXT-01 차세대 공통 코어(`src/core/next/`) 위에 올린 퍼즐 게임. 상자를 밀어 발판을 누르고, 레버와 열쇠로 문을 열어 방 3개의 룬에 도달한다. 상태: 개발 후보(공식 채택 아님).

## 규칙
- 방마다 **이동 횟수 제한**이 있다. 한 칸 걷기·상자 밀기·봉인 풀기가 1회. 벽·닫힌 문에 부딪히면 횟수가 줄지 않는다.
- **상자**는 한 칸씩, 한 개만 밀 수 있다(벽·다른 상자·닫힌 문 쪽으로는 안 밀린다).
- **발판**: 상자나 탐험가가 올라가 있는 동안만 연결된 문이 열린다. `mode: "all"` 문은 연결된 발판이 전부 눌려야 열린다.
- **레버**: 밟을 때마다 연결된 문이 열림/닫힘으로 바뀐다.
- **열쇠**는 밟으면 줍고, **봉인된 문**에 들어가면 1개를 써서 영구히 연다.
- 문은 안에 무언가 서 있는 동안에는 닫히지 않는다.
- 룬(목표)에 닿으면 방 클리어 → 45틱 뒤 다음 방. 마지막 방을 깨면 승리.
- 이동 횟수를 다 쓰면 그 방은 실패. `방 다시`로 그 방만 처음부터 한다.
- 의뢰 4개(첫 방 탈출, 열쇠 사용, 금고 통과, 실패 없이 통과) — 보상 룬은 한 번만 지급된다.

## 조작
| | PC | 모바일 |
| --- | --- | --- |
| 이동·밀기 | 방향키 / WASD | 화면 왼쪽 아래 D-패드, 또는 보드의 칸 탭(그 방향으로 한 칸) |
| 방 다시 | R | `↺ 방` 버튼 |
| 새 게임 | N | `새 게임` 버튼 |
| 음소거 | M | 🔊 버튼 |

## 데이터·저장
- 방(타일·상자·문·발판·레버·열쇠·이동 제한)과 의뢰는 전부 `world.json`(`worldforge/0.1`, 규칙 `game.puzzle`)에 있다. `vault.js`에는 맵 데이터가 없다.
- 저장 키 `aldol-engine.rune-vault-m4.save.v1` (버전형 봉투 `aldol-next-save/1` + 체크섬). 손상·다른 게임·모르는 버전의 저장은 거부하고 새 게임으로 시작한다. 기존 세 게임의 저장 키·형식과 무관하다.
- 입력 프레임: `{ move }` · `{ reset: true }` · `{ next: true }`. 그 밖의 입력은 무시된다.

## 재사용한 공통 모듈
`src/core/next/`: `ecs.js`(엔티티·이벤트), `spatial.js`(타일 격자), `inventory.js`(열쇠·룬), `quest.js`(의뢰·1회 보상), `runtime.js`(고정 스텝·리플레이·스냅샷), `save.js`(저장 키), `manifest.js`(월드 어댑터·타일 행 파서).
`src/render/`: `hud.js`(HUD 킷, forest 테마), `audio.js`, `next/board.js`(보드 씬·셀 피킹·메시 동기화), `next/shell.js`(러너·저장 슬롯·D-패드·프로브).
